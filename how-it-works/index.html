02 / GETTING STARTED

Your Android becomes
the server.

Yevqo pairs a Go Agent running in Termux with a browser-based Control Plane. The product is for Android and Termux; public package distribution and physical Android acceptance are still being finalized.

01

Prepare Android

Use an Android ARM64 device, install Termux from one trusted source, update packages and grant storage access.

pkg update && pkg upgrade
termux-setup-storage
02

Connect the Agent

The Go Agent runs as a Termux service and connects outward to your Control Plane. Pairing uses a dedicated token from Profile → Agent pairing token. Keep that token private; it is not your referral code.

Current package builds are produced by CI, but a refreshed public release and clean-install/upgrade acceptance on physical Android are still launch blockers. Do not rely on older development packages.

03

Create an application

Create a project and application in the dashboard. Yevqo asks the Agent to create the site, attaches it to the project/environment, starts supported runtimes and checks whether the selected port responds.

operational considerations: Yevqo does not provide a hosted cloud runtime. Your Android device runs the workload. Public reachability depends on carrier/router restrictions and a correctly configured domain or tunnel; successful tunnel connection alone does not prove that the public HTTP origin is healthy.
