DOCUMENTATION / PROJECTS


Projects

Organize applications and workloads in your Yevqo workspace.

STRUCTURE

Keep projects separate

Use a separate directory for each application, with its own source code, configuration and runtime requirements.

RUNTIMES

Choose a compatible runtime

Static HTML, Node.js, PHP and Go are starter categories. Compatibility depends on the Android version, device architecture and available Termux packages.

RESOURCES

Plan around device limits

Monitor memory, storage, CPU load and device temperature. Mobile hardware is not equivalent to a dedicated server.

PROJECT COUNT

No artificial project-count limit

Yevqo's planned plans distinguish resources and capabilities rather than limiting the number of projects.

Product status: Yevqo is under active development. This guide describes current general Android/Termux practices and clearly marks planned Yevqo functionality.
