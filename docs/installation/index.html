Installation & requirements

Yevqo uses Android and Termux as an execution environment. Check the device and runtime requirements before installing components.

01

Android architecture

Use a supported Android ARM64 environment for the Android packages. Device firmware and available resources determine practical compatibility.

02

Termux environment

Install Termux from a trusted distribution source. Keep add-ons from the same source to avoid package-signature conflicts.

03

Update packages

Refresh the package index and installed tools before adding project runtimes.

pkg update && pkg upgrade
04

Storage access

Grant storage access only when your workflow requires it.

termux-setup-storage
05

Background execution

Android battery management can stop background processes. Configure device power settings according to your Android version and test service behavior after the screen has been off.

Workload compatibility: Install only the language runtimes and tools required by your applications. Not every Linux package or server workload is available or suitable on Android.
