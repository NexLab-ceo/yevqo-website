Installation &
requirements

Android, Termux and package preparation for a personal server.

01

Android device

A relatively recent Android device is recommended. Available memory, thermal limits, battery policy and storage speed affect what workloads are practical.

02

Install Termux

Use the official Termux distribution. Keep Termux and its add-ons from the same source to avoid signature conflicts.

03

Update packages

Refresh packages before installing development runtimes.

pkg update && pkg upgrade
04

Install only what you need

Install runtimes such as Node.js, PHP or Go only when your project requires them. Check package availability for your device architecture.

05

Background execution

Android may stop background processes to save power. Review battery optimization and test your workload after screen-off periods.

Beta distribution status: The Android ARM64 packages are built and checked by GitHub Actions. The currently published GitHub release is an older development artifact and must not be treated as the current supported installer. A refreshed public release, clean-install/upgrade testing and service-start verification on physical Android are required before general advertising.
