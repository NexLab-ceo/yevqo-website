Yevqo
Agent

The Yevqo Agent is a Go service that runs inside Termux and connects outward to the Control Plane. It executes authenticated, typed device operations for projects and applications.

STATUS

Available for platform testing

The Agent, pairing flow and Android ARM64 build are implemented. A refreshed public package release and physical Android clean-install/upgrade acceptance are still being finalized.

PAIRING

Use a dedicated pairing token

Open Profile → Agent pairing token in the Control Plane, create a token and keep it private. The raw token is shown once; only its SHA-256 hash is stored by the Control Plane. It is separate from referral codes.

SETUP

Configure the Termux service

The all-in-one package provides yevqo-setup and yevqo-setup-agent. A standalone Agent package provides yevqo-setup. Choose the Control Plane WebSocket URL and enter the pairing token when prompted. Do not install the all-in-one and standalone packages into the same Termux environment.

SECURITY

Review permissions and trust boundaries

Build and runtime commands execute with the Termux Agent account permissions; this is not an OS/container sandbox. Only connect repositories and run project code you trust. Keep pairing tokens, source provider credentials and Cloudflare tokens private.

LIMITS

Android controls execution

Background process survival depends on Android battery policy and device firmware. CPU, memory, storage, network access and available Termux packages constrain practical workloads.

platform limitation: CI verifies Go tests, Android ARM64 cross-compilation, frontend build and package assembly. These checks do not replace physical Android install, upgrade, service-start and reboot testing. Do not treat public routing as healthy until the hostname is tested from an external network.
