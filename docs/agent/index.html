Yevqo Agent

The Yevqo Agent is a Go service that runs inside Termux and connects a supported device to the Control Plane. It reports device information and performs supported device-side operations.

ROLE

Connect a device

The Agent establishes an outbound connection to the Control Plane. This allows the workspace to communicate with a device without requiring an inbound connection to the device itself.

PAIRING

Use a dedicated pairing token

Open Profile → Agent pairing token in the Control Plane, create a token and keep it private. The raw token is shown once; only its SHA-256 hash is stored by the Control Plane. It is separate from referral codes.

SETUP

Configure the Termux service

The all-in-one package provides yevqo-setup and yevqo-setup-agent. A standalone Agent package provides yevqo-setup. Choose the Control Plane WebSocket URL and enter the pairing token when prompted. Do not install the all-in-one and standalone packages into the same Termux environment.

SECURITY

Understand execution permissions

Build and runtime commands execute with the Termux Agent account permissions. This is not an OS-level or container sandbox. Only run project code you trust, and keep pairing tokens and access credentials private.

LIMITS

Android controls execution

Background process survival depends on Android battery policy and device firmware. CPU, memory, storage, network access and available Termux packages constrain practical workloads.
