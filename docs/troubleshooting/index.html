Troubleshooting

Checks for common Android, Termux and networking problems.

PACKAGE ERRORS

Update package metadata

Run package update and upgrade, then retry. Check that your Termux installation and add-ons come from compatible sources.

PROCESS STOPS

Review battery restrictions

Android may stop background processes. Review battery optimization settings and test the device under realistic conditions.

PORT UNAVAILABLE

Check listening processes

Confirm the application is running, listening on the expected interface and port, and not blocked by another process.

NOT PUBLICLY REACHABLE

Check CGNAT and firewall

A service can work locally while remaining unreachable from the internet. Check carrier restrictions, router configuration and firewall rules.

DEVICE OVERHEATS

Reduce workload

Lower concurrency, stop unused services and allow the device to cool. Phones have thermal and power limits.

Product status: Yevqo is under active development. This guide describes current general Android/Termux practices and clearly marks planned Yevqo functionality.
