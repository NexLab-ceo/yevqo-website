DOCUMENTATION / DEPLOYMENT

Builds &
deployment

Understand build workflows and the planned project manifest.

BUILD

Prepare your project

Install dependencies and run the project's documented build command in Termux. Review the output before exposing the service.

MANIFEST

yevqo.yml is planned

A project manifest is planned to describe runtime, build steps, start command, environment and exposed port. It is not yet an active deployment specification.

CONTAINERS

Docker builders need Linux

Nixpacks and Railpack typically rely on Linux/container tooling. They should not be assumed to work natively inside a standard Android Termux environment.

STATUS

Dashboard deployment is in development

The complete Yevqo deployment workflow is not released. This guide describes the concepts, not an available one-click deploy feature.

Product status: Yevqo is under active development. This guide describes current general Android/Termux practices and clearly marks planned Yevqo functionality.
