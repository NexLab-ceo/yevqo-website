Getting started

Prepare a supported Android device and understand the components before connecting your environment.

01

Prepare your device

Use a supported Android device with enough free storage and a reliable power source. Device memory, thermal behavior and Android background execution policies affect long-running workloads.

02

Install Termux

Install Termux from a trusted distribution source. Keep Termux and its add-ons from the same distribution to avoid package-signature conflicts.

03

Update the environment

Open Termux and refresh installed packages before adding the runtimes required by your projects.

pkg update && pkg upgrade
04

Install Yevqo components

Install the appropriate Yevqo Control Plane and Agent package for your supported Android architecture. Follow the package-specific installation instructions supplied with the release.

05

Connect and organize

Use the Control Plane's Agent pairing flow to connect a device. Then create a project and add an application to begin managing its supported operations.

Operational note: Android may restrict background processes. Review battery optimization and test your workload under the conditions in which you intend to run it.
