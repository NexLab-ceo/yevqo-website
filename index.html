08 / QUESTIONS

Good questions.
Clear answers.

Everything you might want to know before turning your Android into a server.

All questions ↗

Yevqo is a platform designed to turn an Android device into a personal server environment using Termux and a web workspace.

The intended workflow uses Termux and does not require root for typical supported operations.

The Go Agent and dashboard pairing are implemented and available for beta testing. Public package distribution and physical-device acceptance are still in progress.

Android can run web servers through Termux. Public reachability depends on your network and carrier.
