06 / QUESTIONS

Good questions.
Clear answers.

What is Yevqo?+

Yevqo is an infrastructure management platform built around Android, Termux and connected devices. It brings projects, applications, deployments and device visibility into one control panel.

Does Yevqo require a VPS?+

No VPS is required to run the Control Plane on a supported Android device through Termux. Public access to workloads depends on your network, DNS and routing configuration.

Can I use Android as a server?+

Yes, for supported workloads. Available resources, Android background-execution policies, thermal limits and network restrictions affect what a device can reliably run.

What is an Agent?+

An Agent is the component that connects a supported device to the Yevqo Control Plane and performs supported device-side operations.

Can I manage multiple projects?+

Yes. The current Free offering does not impose a project-count limit. It includes one connected Agent.

Is Yevqo free? Is it open source?+

Yevqo is freeware. It is not open source.
