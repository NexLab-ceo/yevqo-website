FAQ / YEVQO

Questions worth
asking first.

Understand what Yevqo does, how Android fits into the architecture and what to expect from a self-hosted environment.

What is Yevqo?+

Yevqo is an infrastructure management platform built around Android, Termux and connected devices. It brings projects, applications, deployments, builds and logs into one control panel.

Does Yevqo require a VPS?+

No VPS is required to run the Control Plane on a supported Android device through Termux. Public access to workloads depends on your network, DNS and routing configuration.

Can I use Android as a server?+

Android can run supported workloads. Available memory, CPU, storage, thermal behavior, background execution policies and network restrictions affect what a device can reliably host.

What is Termux?+

Termux is an Android terminal and Linux-like environment that provides command-line tools and packages. Yevqo uses it as the runtime environment for its Android components.

What is an Agent?+

An Agent is a device-side service that connects a supported device to the Yevqo Control Plane and performs supported device operations.

Can I manage multiple projects?+

Yes. The current Free offering does not impose a project-count limit. It includes one connected Agent.

Is Yevqo free?+

Yes. Yevqo is freeware.

Is Yevqo open source?+

No. Yevqo is freeware, but it is not open source.

Can I make my applications public?+

Public reachability depends on your carrier or router, firewall, DNS and routing or tunnel configuration. Yevqo does not provide a hosted cloud runtime or automatically guarantee public access.

How do I get started?+

Create an account, prepare a supported Android + Termux environment and follow the installation and Agent connection guides in the documentation.
