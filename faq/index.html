06 / QUESTIONS

Good questions.
Clear answers.

A few things worth knowing before you turn an Android device into a server.

What is Yevqo?

Yevqo is an Android-first server control plane in beta. A Go Agent runs in Termux while the browser dashboard manages projects, applications, deployments, logs and device telemetry.

Do I need root access?

No root is required for the supported Termux workflows. Android permissions, background execution limits and available device resources still apply.

Do I need a VPS?

No VPS is required to run workloads locally on your Android device. Public internet access is a separate networking problem and may require a domain, DNS and a tunnel or reachable public address.

Can I host a public website?

Yevqo can start supported web applications on the device. Public reachability depends on your carrier/router, firewall and correct DNS/tunnel configuration. Domain and Cloudflare routing are beta features; a connected tunnel does not by itself prove the website is reachable.

Is the Yevqo Agent available?

The Go Agent and dashboard pairing are implemented for beta testing. A refreshed public package release and physical Android clean-install/upgrade acceptance are still being finalized.

Is Yevqo free?

The current beta plan is Free and allows one connected Android device. Projects are not limited by count. Public Pro checkout and billing are not available.

Which languages and templates are supported?

Seven starter templates are available: Static Website, PHP Website, PHP JSON API, Node.js HTTP, Node.js JSON API, Go HTTP Application and Custom Language App. The Build Engine can detect additional ecosystems when the required Termux toolchain is installed; compatibility depends on each project and device.

Does Yevqo run Docker on Android?

The native Android build workflow uses Termux tools. Docker-based build providers require a separate compatible Linux executor.

Is Yevqo open source?

Yevqo is freeware, not an open-source product. Redistribution and use are subject to the applicable Yevqo license and terms.

Are AI agents available?

No. AI agents are a roadmap concept and are not part of the current beta.
